## No More Study - 2D Platformer 

A fun, fast-paced 2D platformer built entirely in Python using PyGame.. Themed around the students struggling with studies and dodging the enemies impersonating as the course subjects,
this game features a crisp, clean visual style, crisp shadowless sprites, all generated from AI which is Gemini..

## Prerequisites
To play or modify this game, you will need Python and Pygame installed on your computer...=

### 1. How to install PyGame:
Open your terminal (or command prompt) and run the following command:
```bash
pip install pygame
```

### 2. How to Run the Game
Once you have PyGame installed, follow these steps to play:

### 3. Clone the repository:
```bash
git clone https://github.com/Sanjeev-sharma-09/No-More-Study-2D-Platform-Game-.git
```
### 4. Navigate into the project folder:
```bash
cd No-More-Study-2D-Platform-Game-
```
### 5. Run the main file:
```bash
python main.py
```
